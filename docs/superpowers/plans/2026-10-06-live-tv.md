# Glyph Player — Live TV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Flutter desktop app (Linux + Windows) that imports a 50 MB+ M3U_plus list into SQLite without freezing the UI and plays live channels with embedded libmpv.

**Architecture:** Pure-Dart data layer (parser → SQLite/FTS5 → isolate importer) with no Flutter imports so it is unit-testable and runs in an `Isolate`. Riverpod exposes DB queries to a Netflix/Prime-style UI. `media_kit` renders libmpv into a Flutter texture (Wayland-safe, no `--wid`).

**Tech Stack:** Flutter stable (3.41.x, Dart 3.11), `media_kit` + `media_kit_video` + `media_kit_libs_linux` / `media_kit_libs_windows_video`, `sqlite3` (FTS5), `flutter_riverpod`, `http`, `path_provider`, `flutter_secure_storage`.

**Spec:** `docs/superpowers/specs/2026-10-06-live-tv-design.md`

## Global Constraints

- Platforms: `linux` and `windows` only (`flutter create --platforms=linux,windows`).
- v1 surfaces **Live only**; the DB stores all three types (`live`, `movie`, `series`), type decided by the URL path segment, never by group name.
- Category = `group-title` with the prefix `Canais | ` stripped.
- Import/parse runs in an `Isolate`; the UI thread never parses or waits on the import.
- Playlist URL (contains credentials) lives only in the OS secure store; `*.m3u` and `*.m3u8` stay git-ignored; the temp download is deleted after import.
- Stream identity = numeric id from the URL's last path segment (extension removed), unique per `(type, id)`.
- No EPG, movies UI, series UI, distributors, auto-advance, multiple lists, or remote APIs besides the playlist URL.
- Visual design comes from the `impeccable` and `frontend-design` skills; Flutter code follows the installed `.agents/skills/flutter-*` skills.
- Commits only with user approval of this plan (each task ends with a commit step).

## Review Focus

1. Channel names containing commas, and empty `tvg-name`/`tvg-logo`/`tvg-id`: name must be the text after the attributes (Task 2).
2. `#EXTINF` without a following URL, or URL whose path is not `/live|movie|series/`: entry skipped, never crashes (Task 2).
3. Malformed UTF-8 bytes in the list: import continues (Task 4).
4. Interrupted/truncated download or empty file: existing data must NOT be wiped (Tasks 4).
5. Search text with FTS5 specials (`"`, `*`, `-`, `(`, `:`): must not throw, returns results or empty (Task 3).
6. No list configured / zero live channels: UI shows an empty state with a path to Settings, not a blank screen (Task 7).

```dart
// lib/data/m3u_parser.dart
import 'stream_entry.dart';

final _attr = RegExp(r'\s*([\w-]+)="([^"]*)"');
const _livePrefix = 'Canais | ';

/// Parses M3U_plus lines into entries. Skips malformed or unknown-type entries.
Stream<StreamEntry> parseM3u(Stream<String> lines) async* {
  String? inf;
  await for (final raw in lines) {
    final line = raw.trim();
    if (line.isEmpty) continue;
    if (line.startsWith('#EXTINF')) {
      inf = line;
      continue;
    }
    if (line.startsWith('#') || inf == null) continue;
    final entry = _entry(inf, line);
    inf = null;
    if (entry != null) yield entry;
  }
}

StreamEntry? _entry(String inf, String url) {
  final uri = Uri.tryParse(url);
  if (uri == null || uri.pathSegments.length < 2) return null;
  final type = switch (uri.pathSegments.first) {
    'live' => StreamType.live,
    'movie' => StreamType.movie,
    'series' => StreamType.series,
    _ => null,
  };
  if (type == null) return null;

  final attrs = <String, String>{};
  var pos = inf.indexOf(' ');
  if (pos < 0) return null;
  while (true) {
    final m = _attr.matchAsPrefix(inf, pos);
    if (m == null) break;
    attrs[m.group(1)!] = m.group(2)!;
    pos = m.end;
  }
  final comma = inf.indexOf(',', pos);
  var name = comma < 0 ? '' : inf.substring(comma + 1).trim();
  if (name.isEmpty) name = attrs['tvg-name'] ?? '';
  if (name.isEmpty) return null;

  final last = uri.pathSegments.last;
  final dot = last.lastIndexOf('.');
  final id = dot > 0 ? last.substring(0, dot) : last;

  var group = attrs['group-title'] ?? '';
  if (group.startsWith(_livePrefix)) group = group.substring(_livePrefix.length);

  return StreamEntry(
    type: type,
    id: id,
    name: name,
    group: group,
    logo: attrs['tvg-logo'] ?? '',
    url: url,
  );
}
```

```dart
// lib/data/database.dart
import 'package:sqlite3/sqlite3.dart';

import 'stream_entry.dart';

class Channel {
  const Channel({
    required this.type,
    required this.id,
    required this.name,
    required this.group,
    required this.logo,
    required this.url,
  });

  final String type, id, name, group, logo, url;
}

const _schema = '''
CREATE TABLE IF NOT EXISTS streams(
  type TEXT NOT NULL, id TEXT NOT NULL, name TEXT NOT NULL, grp TEXT NOT NULL,
  logo TEXT NOT NULL, url TEXT NOT NULL, run INTEGER NOT NULL,
  PRIMARY KEY(type, id));
CREATE INDEX IF NOT EXISTS streams_type_grp ON streams(type, grp);
CREATE VIRTUAL TABLE IF NOT EXISTS streams_fts USING fts5(
  name, content='streams', content_rowid='rowid',
  tokenize='unicode61 remove_diacritics 2');
CREATE TABLE IF NOT EXISTS favorites(
  type TEXT NOT NULL, id TEXT NOT NULL, PRIMARY KEY(type, id));
CREATE TABLE IF NOT EXISTS recents(
  type TEXT NOT NULL, id TEXT NOT NULL, watched_at INTEGER NOT NULL,
  PRIMARY KEY(type, id));
''';

const _cols = 's.type, s.id, s.name, s.grp, s.logo, s.url';

class Db {
  Db._(this._db) {
    _db.execute('PRAGMA journal_mode=WAL; PRAGMA busy_timeout=5000; PRAGMA synchronous=NORMAL;');
    _db.execute(_schema);
  }

  factory Db.open(String path) => Db._(sqlite3.open(path));
  factory Db.memory() => Db._(sqlite3.openInMemory());

  final Database _db;

  void close() => _db.dispose();

  int beginRun() =>
      (_db.select('SELECT COALESCE(MAX(run), 0) + 1 AS r FROM streams').first['r'] as int);

  void upsertBatch(List<StreamEntry> entries, int run) {
    final stmt = _db.prepare(
      'INSERT INTO streams(type,id,name,grp,logo,url,run) VALUES(?,?,?,?,?,?,?) '
      'ON CONFLICT(type,id) DO UPDATE SET name=excluded.name, grp=excluded.grp, '
      'logo=excluded.logo, url=excluded.url, run=excluded.run',
    );
    _db.execute('BEGIN');
    try {
      for (final e in entries) {
        stmt.execute([e.type.name, e.id, e.name, e.group, e.logo, e.url, run]);
      }
      _db.execute('COMMIT');
    } catch (_) {
      _db.execute('ROLLBACK');
      rethrow;
    } finally {
      stmt.dispose();
    }
  }

  /// Drops rows not seen in [run] and rebuilds the search index. Call only
  /// after a fully successful import.
  void finishRun(int run) {
    _db.execute('DELETE FROM streams WHERE run <> ?', [run]);
    _db.execute("INSERT INTO streams_fts(streams_fts) VALUES('rebuild')");
  }

  List<String> liveGroups() => _db
      .select("SELECT grp FROM streams WHERE type='live' GROUP BY grp ORDER BY MIN(rowid)")
      .map((r) => r['grp'] as String)
      .toList();

  List<Channel> liveChannels(String group) => _channels(
        "SELECT $_cols FROM streams s WHERE s.type='live' AND s.grp=? ORDER BY s.rowid",
        [group],
      );

  List<Channel> searchLive(String text, {int limit = 60}) {
    final tokens = text
        .split(RegExp(r'\s+'))
        .where((t) => t.isNotEmpty)
        .map((t) => '"${t.replaceAll('"', '""')}"*')
        .join(' ');
    if (tokens.isEmpty) return const [];
    return _channels(
      "SELECT $_cols FROM streams_fts f JOIN streams s ON s.rowid = f.rowid "
      "WHERE streams_fts MATCH ? AND s.type='live' ORDER BY f.rank LIMIT ?",
      [tokens, limit],
    );
  }

  List<Channel> favorites() => _channels(
        "SELECT $_cols FROM favorites f JOIN streams s ON s.type=f.type AND s.id=f.id "
        "WHERE s.type='live' ORDER BY s.name",
        const [],
      );

  List<Channel> recents({int limit = 20}) => _channels(
        "SELECT $_cols FROM recents r JOIN streams s ON s.type=r.type AND s.id=r.id "
        "WHERE s.type='live' ORDER BY r.watched_at DESC LIMIT ?",
        [limit],
      );

  bool isFavorite(String type, String id) => _db
      .select('SELECT 1 FROM favorites WHERE type=? AND id=?', [type, id])
      .isNotEmpty;

  void setFavorite(String type, String id, bool value) {
    if (value) {
      _db.execute('INSERT OR IGNORE INTO favorites(type,id) VALUES(?,?)', [type, id]);
    } else {
      _db.execute('DELETE FROM favorites WHERE type=? AND id=?', [type, id]);
    }
  }

  void markWatched(String type, String id, DateTime at) => _db.execute(
        'INSERT INTO recents(type,id,watched_at) VALUES(?,?,?) '
        'ON CONFLICT(type,id) DO UPDATE SET watched_at=excluded.watched_at',
        [type, id, at.millisecondsSinceEpoch],
      );

  List<Channel> _channels(String sql, List<Object?> args) => _db
      .select(sql, args)
      .map((r) => Channel(
            type: r['type'] as String,
            id: r['id'] as String,
            name: r['name'] as String,
            group: r['grp'] as String,
            logo: r['logo'] as String,
            url: r['url'] as String,
          ))
      .toList();
}
```

```dart
// lib/data/downloader.dart
import 'dart:io';
import 'package:http/http.dart' as http;

/// Streams [url] to `dest.path + '.part'` and renames onto [dest] only after a
/// complete, correctly sized download. Any failure leaves [dest] untouched.
Future<void> downloadTo(Uri url, File dest, {http.Client? client}) async {
  final c = client ?? http.Client();
  final part = File('${dest.path}.part');
  try {
    final res = await c.send(http.Request('GET', url)).timeout(const Duration(seconds: 30));
    if (res.statusCode != 200) throw HttpException('HTTP ${res.statusCode}', uri: url);
    var received = 0;
    await res.stream.map((chunk) {
      received += chunk.length;
      return chunk;
    }).pipe(part.openWrite());
    final expected = res.contentLength;
    if (expected != null && received != expected) {
      throw HttpException('Truncated download: $received of $expected bytes', uri: url);
    }
    await part.rename(dest.path);
  } catch (_) {
    if (await part.exists()) await part.delete();
    rethrow;
  } finally {
    if (client == null) c.close();
  }
}
```

```dart
// lib/data/importer.dart
import 'dart:convert';
import 'dart:io';
import 'dart:isolate';

import 'database.dart';
import 'm3u_parser.dart';
import 'stream_entry.dart';

const _batchSize = 5000;

/// Parses [file] and upserts it into the DB at [dbPath]. Old rows are removed
/// only after the whole file parsed with at least one entry.
Future<int> importFile({
  required String dbPath,
  required File file,
  void Function(int count)? onProgress,
}) async {
  final db = Db.open(dbPath);
  try {
    final run = db.beginRun();
    final batch = <StreamEntry>[];
    var count = 0;
    final lines = file
        .openRead()
        .transform(const Utf8Decoder(allowMalformed: true))
        .transform(const LineSplitter());
    await for (final e in parseM3u(lines)) {
      batch.add(e);
      count++;
      if (batch.length >= _batchSize) {
        db.upsertBatch(batch, run);
        batch.clear();
        onProgress?.call(count);
      }
    }
    if (count == 0) throw const FormatException('Playlist has no entries');
    db.upsertBatch(batch, run);
    db.finishRun(run);
    onProgress?.call(count);
    return count;
  } finally {
    db.close();
  }
}

/// Runs [importFile] in a separate isolate; [onProgress] runs on the caller.
Future<int> importInBackground(String dbPath, File file, void Function(int) onProgress) async {
  final port = ReceivePort();
  final sub = port.listen((m) => onProgress(m as int));
  try {
    return await _runIsolate(dbPath, file, port.sendPort);
  } finally {
    await sub.cancel();
    port.close();
  }
}

// Separate scope so the isolate closure captures only sendable values.
Future<int> _runIsolate(String dbPath, File file, SendPort send) =>
    Isolate.run(() => importFile(dbPath: dbPath, file: file, onProgress: send.send));
```

```dart
    FutureProvider<List<String>>((ref) async => ref.watch(dbProvider).liveGroups());

    (ref, group) async => ref.watch(dbProvider).liveChannels(group));
final favoritesProvider =
    FutureProvider<List<Channel>>((ref) async => ref.watch(dbProvider).favorites());
final recentsProvider =
    FutureProvider<List<Channel>>((ref) async => ref.watch(dbProvider).recents());
final searchProvider = FutureProvider.family<List<Channel>, String>(
    (ref, q) async => ref.watch(dbProvider).searchLive(q));

sealed class ImportState {
  const ImportState();
}

class ImportIdle extends ImportState {
  const ImportIdle();
}

class ImportRunning extends ImportState {
  const ImportRunning({this.count = 0, this.downloading = true});
  final int count;
  final bool downloading;
}

class ImportFailed extends ImportState {
  const ImportFailed(this.message);
  final String message;
}

class ImportController extends Notifier<ImportState> {
  @override
  ImportState build() => const ImportIdle();

  Future<void> refresh() async {
    if (state is ImportRunning) return;
    final url = await ref.read(playlistUrlStoreProvider).read();
    if (url == null || Uri.tryParse(url)?.hasScheme != true) {
      state = const ImportFailed('Configure a URL da lista em Configurações.');
      return;
    }
    final paths = ref.read(appPathsProvider);
    final file = File(paths.downloadPath);
    state = const ImportRunning();
    try {
      await downloadTo(Uri.parse(url), file);
      state = const ImportRunning(downloading: false);
      await importInBackground(
        paths.dbPath,
        file,
        (n) => state = ImportRunning(count: n, downloading: false),
      );
      state = const ImportIdle();
      ref
        ..invalidate(liveGroupsProvider)
        ..invalidate(groupChannelsProvider)
        ..invalidate(favoritesProvider)
        ..invalidate(recentsProvider);
    } catch (e) {
      state = ImportFailed('Falha ao atualizar a lista: $e');
    } finally {
      if (await file.exists()) await file.delete();
    }
  }
}
```

```dart
int zapIndex(int current, int delta, int length) => (current + delta) % length;

class PlayerPage extends ConsumerStatefulWidget {
  const PlayerPage({super.key, required this.queue, required this.index});
  final List<Channel> queue;
  final int index;
  @override
  ConsumerState<PlayerPage> createState() => _PlayerPageState();
}

class _PlayerPageState extends ConsumerState<PlayerPage> {
  late final Player _player = Player();
  late final VideoController _video = VideoController(_player);
  late int _index = widget.index;
  bool _panel = false;

  Channel get _current => widget.queue[_index];

  @override
  void initState() {
    super.initState();
    _open();
  }

  void _open() {
    final c = _current;
    _player.open(Media(c.url));
    ref.read(dbProvider).markWatched(c.type, c.id, DateTime.now());
    ref.invalidate(recentsProvider);
  }

  void _zap(int delta) {
    setState(() {
      _index = zapIndex(_index, delta, widget.queue.length);
      _panel = true;
    });
    _open();
  }

  @override
  void dispose() {
    _player.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final db = ref.watch(dbProvider);
    return CallbackShortcuts(
      bindings: {
        const SingleActivator(LogicalKeyboardKey.arrowUp): () => _zap(-1),
        const SingleActivator(LogicalKeyboardKey.arrowDown): () => _zap(1),
        const SingleActivator(LogicalKeyboardKey.keyL): () => setState(() => _panel = !_panel),
```

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../../state/providers.dart';
import 'channel_card.dart';

class ChannelSearchDelegate extends SearchDelegate<void> {
  ChannelSearchDelegate(this.ref) : super(searchFieldLabel: 'Buscar canal');
  final WidgetRef ref;

  @override
  List<Widget> buildActions(BuildContext context) => [
        if (query.isNotEmpty)
          IconButton(icon: const Icon(Icons.clear), onPressed: () => query = ''),
      ];

  @override
  Widget buildLeading(BuildContext context) =>
      IconButton(icon: const Icon(Icons.arrow_back), onPressed: () => close(context, null));

  @override
  Widget buildSuggestions(BuildContext context) => _results();
  @override
  Widget buildResults(BuildContext context) => _results();

  Widget _results() => Consumer(builder: (context, ref, _) {

                    crossAxisSpacing: 16,
                    mainAxisSpacing: 16,
                  ),
                  itemCount: list.length,
                  itemBuilder: (_, i) => ChannelCard(queue: list, index: i),
                ),
        );
      });
}
```
