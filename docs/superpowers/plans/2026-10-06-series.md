# Series Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Series browsing by distributor with series → season → episode, a favorites list, a Continue list (with remove) and auto-advance to the next episode.

**Architecture:** Series/season/episode are parsed once at import into indexed `streams` columns (with an in-place migration for existing databases). Pure functions decide "next episode" and "which episode to continue". The movie player becomes a generic VOD player (queue + optional `nextOf`), reused for movies and episodes; an isolated overlay widget implements the 5 s auto-advance countdown.

**Tech Stack:** Flutter/Dart, `sqlite3`, `flutter_riverpod`, `media_kit` (all already in `pubspec.yaml`; no new dependencies).

**Spec:** `docs/superpowers/specs/2026-10-06-series-design.md`

## Global Constraints

- Series key is `(grp, series_name)`; distributor label = group with the prefix `Series | ` removed; groups without that prefix are shown as their own sections.
- Only `type='series'` rows use the new columns `series_name`, `season`, `episode`; defaults `''`, `0`, `0`.
- A name that does not match `<name> S<ss>E<ee>` is never dropped: series name = full name, season 0, episode 0.
- Duplicate (season, episode) rows inside a series stay visible; auto-advance and Continue skip rows with the same (season, episode) as the current one.
- Finished = more than 95% watched (same threshold as `resumePosition`).
- Adult filter (`isAdultGroup`) applies to sections, series lists, favorites and Continue.
- Removing from Continue never deletes episode progress; it writes `series_hidden(grp, series_name, hidden_at)`. Series returns when any episode progress is newer than `hidden_at`.
- No new dependencies; no remote APIs; posters are the existing `tvg-logo` URLs.
- Windows is untested from this machine.
- Commit only on the `feat/series` branch; merge to `main` only when the user asks.

## Review Focus

1. Names with odd spacing/case (`S1E2`, `s01 e02`, `Série 2 S01E01`) and names that do not match at all (Task 1).
2. Migration of an old-schema DB: runs once, is idempotent, keeps favorites/progress, fills every series row (Task 2).
3. Duplicate episodes: shown in the list, skipped by auto-advance/Continue (Tasks 3, 4).
4. Last episode of a series and last season: auto-advance does nothing; Continue on a finished last episode reopens it (Task 4).
5. Removed series reappearing only after new watching, not on restart (Task 3).
6. Series with no poster or a broken poster: monogram, no crash (Task 6).

```dart
// lib/data/series_title.dart
class SeriesTitle {
  const SeriesTitle(this.name, this.season, this.episode);
  final String name;
  final int season, episode;
}

final _marker = RegExp(r'\s*[Ss](\d+)\s*[Ee](\d+)');

/// Splits `Name S01E08` into name, season and episode. A name without the
/// marker (or made only of it) is kept whole with season/episode 0.
SeriesTitle parseSeriesName(String raw) {
  final s = raw.trim();
  final m = _marker.firstMatch(s);
  if (m == null || m.start == 0) return SeriesTitle(s, 0, 0);
  return SeriesTitle(
    s.substring(0, m.start).trim(),
    int.parse(m.group(1)!),
    int.parse(m.group(2)!),
  );
}
```

```dart
  /// Adds the series columns to databases created before them and fills them
  /// from the stored names. Idempotent.
  void _migrate() {
    final cols = _db
        .select('PRAGMA table_info(streams)')
        .map((r) => r['name'] as String)
        .toSet();
    if (!cols.contains('series_name')) {
      _db.execute('BEGIN');
      try {
        _db.execute("ALTER TABLE streams ADD COLUMN series_name TEXT NOT NULL DEFAULT ''");
        _db.execute('ALTER TABLE streams ADD COLUMN season INTEGER NOT NULL DEFAULT 0');
        _db.execute('ALTER TABLE streams ADD COLUMN episode INTEGER NOT NULL DEFAULT 0');
        final upd = _db.prepare(
          'UPDATE streams SET series_name=?, season=?, episode=? WHERE type=? AND id=?',
        );
        try {
          final rows = _db.select("SELECT id, name FROM streams WHERE type='series'");
          for (final r in rows) {
            final t = parseSeriesName(r['name'] as String);
            upd.execute([t.name, t.season, t.episode, 'series', r['id']]);
          }
        } finally {
          upd.close();
        }
        _db.execute('COMMIT');
      } catch (_) {
        _db.execute('ROLLBACK');
        rethrow;
      }
    }
    _db.execute(
      'CREATE INDEX IF NOT EXISTS streams_series ON streams(type, grp, series_name)',
    );
    _db.execute('PRAGMA user_version = 1');
  }
```

```dart
class SeriesSummary {
  const SeriesSummary(this.group, this.name, this.poster, this.seasons, this.episodes);
  final String group, name, poster;
  final int seasons, episodes;
}

const _summaryCols =
    's.grp, s.series_name, MAX(s.logo) AS poster, COUNT(DISTINCT s.season) AS seasons, COUNT(*) AS episodes';

  List<SeriesSummary> _summaries(String sql, List<Object?> args) => _db
      .select(sql, args)
      .map((r) => SeriesSummary(
            r['grp'] as String, r['series_name'] as String, r['poster'] as String,
            r['seasons'] as int, r['episodes'] as int,
          ))
      .toList();

  List<SeriesSummary> seriesIn(String group) => _summaries(
        "SELECT $_summaryCols FROM streams s WHERE s.type='series' AND s.grp=? "
        "GROUP BY s.series_name ORDER BY s.series_name COLLATE NOCASE",
        [group],
      );

  List<SeriesSummary> seriesFavorites() => _summaries(
        "SELECT $_summaryCols FROM series_favorites f JOIN streams s "
        "ON s.type='series' AND s.grp=f.grp AND s.series_name=f.series_name "
        "GROUP BY s.grp, s.series_name ORDER BY s.series_name COLLATE NOCASE",
        const [],
      );

  bool isSeriesFavorite(String group, String name) => _db
      .select('SELECT 1 FROM series_favorites WHERE grp=? AND series_name=?', [group, name])
      .isNotEmpty;

  void setSeriesFavorite(String group, String name, bool value) {
    if (value) {
      _db.execute('INSERT OR IGNORE INTO series_favorites(grp,series_name) VALUES(?,?)', [group, name]);
    } else {
      _db.execute('DELETE FROM series_favorites WHERE grp=? AND series_name=?', [group, name]);
    }
  }

  /// One entry per series with any episode progress, newest first, minus the
  /// ones the user removed and has not watched since.
  List<SeriesSummary> continueSeries({int limit = 20}) => _summaries(
        "WITH w AS ("
        " SELECT s.grp AS g, s.series_name AS n, MAX(p.updated_at) AS last"
        " FROM progress p JOIN streams s ON s.type=p.type AND s.id=p.id"
        " WHERE s.type='series' GROUP BY s.grp, s.series_name) "
        "SELECT $_summaryCols FROM w JOIN streams s "
        "ON s.type='series' AND s.grp=w.g AND s.series_name=w.n "
        "WHERE NOT EXISTS (SELECT 1 FROM series_hidden h "
        " WHERE h.grp=w.g AND h.series_name=w.n AND h.hidden_at >= w.last) "
        "GROUP BY w.g, w.n ORDER BY w.last DESC LIMIT ?",
        [limit],
      );

  void hideSeries(String group, String name, DateTime at) => _db.execute(
        'INSERT INTO series_hidden(grp,series_name,hidden_at) VALUES(?,?,?) '
        'ON CONFLICT(grp,series_name) DO UPDATE SET hidden_at=excluded.hidden_at',
        [group, name, at.millisecondsSinceEpoch],
      );

  /// Marks an item as watched now without touching its resume position.
  void touchProgress(String type, String id, DateTime at) => _db.execute(
        'INSERT INTO progress(type,id,position_ms,duration_ms,updated_at) VALUES(?,?,0,0,?) '
        'ON CONFLICT(type,id) DO UPDATE SET updated_at=excluded.updated_at',
        [type, id, at.millisecondsSinceEpoch],
      );

  int seriesCount(String group) => _db
      .select(
```

```dart
// lib/data/resume.dart  (replace the file)
const _minResumeMs = 30000;
const _finishedFraction = 0.95;

/// More than 95% watched, with a known duration.
bool isFinished(int positionMs, int durationMs) =>
    durationMs > 0 && positionMs / durationMs > _finishedFraction;

/// Where to resume playback, or null to start from the beginning.
Duration? resumePosition(int positionMs, int durationMs) {
  if (positionMs < _minResumeMs || isFinished(positionMs, durationMs)) {
    return null;
  }
  return Duration(milliseconds: positionMs);
}
```

```dart
// lib/data/series_nav.dart
import 'database.dart';
import 'resume.dart';

/// First later index whose (season, episode) differs from the current one, so
/// duplicate rows of the same episode are skipped. Null on the last episode.
int? nextIndex(List<Episode> eps, int current) {
  final cur = eps[current];
  for (var i = current + 1; i < eps.length; i++) {
    if (eps[i].season != cur.season || eps[i].episode != cur.episode) return i;
  }
  return null;
}

/// Episode to open for "Continue": the last watched one, or the next when it
/// was finished (and there is a next).
int continueIndex(List<Episode> eps, int lastIndex, Progress progress) =>
    isFinished(progress.positionMs, progress.durationMs)
        ? (nextIndex(eps, lastIndex) ?? lastIndex)
        : lastIndex;
```

```dart
import 'dart:async';
import 'package:flutter/material.dart';
import '../../ui/theme.dart';

class AutoAdvanceOverlay extends StatefulWidget {
  const AutoAdvanceOverlay({
    super.key,
    required this.title,
    required this.onNow,
    required this.onCancel,
    this.seconds = 5,
  });
  final String title;
  final VoidCallback onNow, onCancel;
  final int seconds;

  @override
  State<AutoAdvanceOverlay> createState() => _AutoAdvanceOverlayState();
}

class _AutoAdvanceOverlayState extends State<AutoAdvanceOverlay> {
  late int _left = widget.seconds;
  Timer? _timer;
  bool _done = false;

  @override
  void initState() {
    super.initState();
    _timer = Timer.periodic(const Duration(seconds: 1), (_) {
      if (_left <= 1) {
        _finish(widget.onNow);
      } else {
        setState(() => _left--);
      }
    });
  }

  void _finish(VoidCallback action) {
    if (_done) return;
    _done = true;
    _timer?.cancel();
    action();
  }

  @override
  void dispose() {
    _timer?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) => Positioned(
        right: 24,
        bottom: 96,
        child: Material(
          color: Tokens.panel,
          borderRadius: BorderRadius.circular(Tokens.radius),
          child: Padding(
            padding: const EdgeInsets.all(16),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text('Próximo episódio em $_left s',
                    style: const TextStyle(fontWeight: FontWeight.w600)),
                const SizedBox(height: 4),
                Text(widget.title, style: const TextStyle(color: Tokens.textDim)),
                const SizedBox(height: 12),
                Row(mainAxisSize: MainAxisSize.min, children: [
```
